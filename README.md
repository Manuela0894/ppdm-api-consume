# Cosmos Explorer

Aplicativo mobile desenvolvido em React Native utilizando a API da NASA.

## API Utilizada

NASA Open API:

https://api.nasa.gov/

## Funcionalidades

- Listagem de imagens astronômicas
- Tela de detalhes
- Favoritos com AsyncStorage
- Tratamento de loading
- Tratamento de erro
- Navegação entre telas

## Tecnologias

- React Native
- Expo
- Axios
- React Navigation
- AsyncStorage


## Estrutura de Pastas

components: componentes reutilizáveis
screens: telas da aplicação
services: comunicação com API
storage: persistência local
styles: temas e estilos globais
routes: navegação
